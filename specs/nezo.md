## コンセプト

- 題材：寝相
- ひとひねり：一晩の寝返りを早送りで見守り、クッションと毛布で、寝ている人を布団の上に寝かせ続ける。直接は動かせず、道具を置いて誘導するだけ
- 朝7時の寝姿が「写真」になり、変な寝相にも名前（称号）が付く。称号は集められる（全17種）

## ルール

1. 夜11時から朝7時まで、寝ている人がときどき寝返り・回転・ずり上がり／ずり下がり・もぞもぞをする。夜が深くなるほど動く間隔が短くなり、大寝返り・大回転も起きる
2. 画面下のトレイで道具を選び、畳や布団をタップして置く。置いた物をタップすると回収する
3. **クッション**（最大3個）：体（胸・お腹・腰・ひざ・足）が当たると止まり、「ボヨン」と押し返す。4個目を置くと、いちばん古いクッションが動く。体の上には置けない
   - 足元にあるクッションは、けとばされることがある
   - **顔の近くのクッション**（v3.0から）：頭はクッションに止められず、押しのけて動く。顔にクッションが当たっているあいだは息苦しく、眠りの質が下がる。動くときに、顔の近くのクッションを払いのけることがある
   - **体を挟むクッション**（v3.1から）：胴体（胸・お腹・腰）が左右両側からクッションに当たっているあいだは寝苦しく、眠りの質が下がる。動くときに、挟んでいるクッションを押しのけることがある。片側だけなら減点しない（寝返りを止める本来の使い方）
4. **毛布**（1枚）：置くと、寝ている人が寄ってくる。体に重なると毛布にくるまり、しばらくおとなしくなる
   - くるまっているあいだ、寝ている人に「暑さ」がたまる。12〜17秒分たまると毛布をけとばす（v3.1から）
   - 暑さは毛布ではなく寝ている人の側にたまるので、はがしてかけ直しても減らない。毛布から出ているあいだに少しずつ冷める（1秒あたり0.5）
   - けとばしたあと8秒間は暑がって、毛布をかけてもくるまらない（「あつい…」と表示）
5. 布団から体が出ると「布団から落ちた」、部屋の壁にぶつかると「壁ドン」
6. 朝7時に目覚ましが鳴り、その瞬間の寝姿が写真になって採点される

## 得点と称号

### 安眠スコア（100点満点）

| 項目 | 配点 | 計算 |
|---|---|---|
| 安眠度 | 60 | 夜のあいだの「眠りの質」の平均 × 60。眠りの質は、体の95%以上が布団の上なら1、半分以下なら0。顔にクッションが当たっているあいだは × 0.35、胴体を両側から挟まれているあいだは × 0.5 |
| ぐっすり | 20 | 20 − 落下 × 5 − 壁ドン × 3（0未満にはならない） |
| 朝の寝姿 | 20 | 布団の上にいる割合 × 8 ＋ まっすぐ寝ているか（頭が上を向いている度合いの2乗）× 6 ＋ まくらに頭がのっていれば 6 |

### 称号（朝の写真の名前。上から順に判定）

| 条件 | 称号 |
|---|---|
| 毛布にくるまって布団の外 | 毛布ごと家出 |
| 毛布にくるまっている | 朝のみのむし |
| 逆さまで布団の外 | 逆さまで布団の外 |
| 85点以上・あおむけ・布団の上・まくらに頭で、大の字 | 美しい大の字 |
| 同じ条件で、気をつけ | 直立不動の眠り |
| 逆さまで布団の上 | まくら逆転の名人 |
| 全力疾走の姿勢で、布団からはみ出している | 夢の中で全力疾走 |
| 落下4回以上 | 布団ダイブ常習犯 |
| 壁ドン5回以上 | 夜通し壁ドン |
| 布団に対して横向き | 布団にT字路 |
| 80点以上・落下なし・クッションで8回以上止めた | 鉄壁のクッション |
| 80点以上 | ホテルの朝 |
| 変な要素が3つ以上（逆さま・布団の外・遠く離れた・うつぶせ・変な姿勢・みのむし・横向き） | 寝相の芸術家 |
| 変な要素が2つ | 朝のミステリー |
| 布団の外 | 畳で寝る人 |
| 60点以上 | まあまあ安眠 |
| それ以外 | ふつうの朝 |

寝姿は7種類：気をつけ、大の字、バンザイ、ひこうき、4の字、全力疾走、まるまり（横向きのとき）。

### シェア

- 文章：`寝相コントロールで安眠スコア○点。` ／ `朝7時の寝姿は「称号」でした（落下○回、壁ドン○回）` ／ `#寝相コントロール` ／ページのURL
- 写真の添付（v3.0から）：結果画面を出したときに、朝の写真の下に称号・ひとこと・安眠スコア・ハッシュタグを入れた画像（1080×1411のJPEG）をメモリ上で作る。共有ボタンで、文章と一緒にシェア画面へ渡す
  - 画像はダウンロードしない（利用者の端末に勝手に保存しない）
  - 画像の添付に対応していない環境では、これまでどおり文章だけで共有する（シェア画面 → Xの投稿画面 → コピーの順）
- リンクのサムネイル（OGP）は固定の `ogp.png`。GitHub Pagesでは結果ごとにサムネイルを変えられないため、写真は添付で共有する

## 主要パラメータ

| 名前 | 値 | 意味 |
|---|---|---|
| `NIGHT_SEC` | 72 | 23:00〜7:00 の長さ（秒） |
| `ROOM` / `FUTON` | 320×440 / 120×214（cm） | 部屋と布団の大きさ |
| `MAX_CUSHION` / `MAX_BLANKET` | 3 / 1 | 置ける数 |
| `CUSH_R` | 17 | クッションの半径 |
| `FACE_R` | 35（頭の半径13＋クッション17＋5） | 頭の中心からこの距離にクッションがあると「顔に当たっている」 |
| `FACE_Q` | 0.35 | 顔にクッションが当たっているあいだの眠りの質の倍率 |
| `SWAT_P` | 0.6 | 動くときに、顔の近く（`FACE_R`＋8cm以内）のクッションを払いのける確率 |
| `PINCH_Q` | 0.5 | 胴体を左右両側から挟まれているあいだの眠りの質の倍率（胴体の円からクッションまで4cm以内を「当たっている」とする） |
| `PINCH_P` | 0.5 | 動くときに、挟んでいるクッションを押しのける確率（30〜50cm飛ばす） |
| `HEAT_MIN` / `HEAT_MAX` | 12 / 17 | 毛布にくるまっていられる秒数の範囲（けとばすたびに選び直す） |
| `HEAT_COOL` | 0.5 | 毛布から出ているあいだ、暑さが1秒あたりに冷める量 |
| `HOT_SEC` | 8 | 毛布をけとばしたあと、毛布をいやがる秒数 |
| 動く間隔 | 2.5秒 → 1.55秒（夜が深くなるほど短い）× 0.75〜1.25。毛布にくるまっていると × 1.75 | |
| 動きの割合 | 寝返り47%、回転22%、ずれ16%、もぞもぞ15% | 足元のクッションがあれば40%でけとばす |
| 寝返りの距離 | 26〜40cm（大寝返りは × 1.85） | |
| `SCORE` | 安眠度60、ぐっすり20（落下−5、壁ドン−3）、朝の寝姿20（布団8・向き6・まくら6） | |

## 見た目・演出

- 真上から見た和室：畳、青海波の敷布団とまくら、障子越しの月明かり（朝は朝日）
- 寝ている人は水色の縞のパジャマ。手足の角度で7種類の寝姿を作り、姿勢の切り替えは補間して動く。頭の上に「Z」が浮かぶ（布団の外では寒そうな色）
- クッション（青緑）は当たるとつぶれて少しすべり、けとばされたり払いのけられたりすると回転しながら飛ぶ。毛布（赤）はくるまると体に巻きつく
- 落下・壁ドンで画面が揺れ、落下時は端末が振動に対応していれば短く振動する
- 朝7時：目覚ましの音と時計の点滅、シャッター音とフラッシュのあと、写真が現像されるように現れる
- 効果音（Web Audio）：寝返り、大寝返り、回転、大回転、ずれ、もぞもぞ、クッションで止まる、壁、落下、布団に戻る、毛布にくるまる、毛布・クッションをけとばす（払いのけも同じ音）、置く、回収、置けない、目覚まし、シャッター、結果、開始
- ライト・ダークモード対応。動きを減らす設定では、写真の現像アニメーションなどを止める

## コンセプト

- 題材：ジムでの筋トレ
- ひとひねり：鍛えた部位だけが育つ。バランスよく鍛えれば「黄金比ボディ」、偏らせれば「ふくらはぎダイヤモンド」のようなおもしろい体になる。きれいな体も、おもしろい体も、どちらもゴールになる
- 結果は「美しさ」と「おもしろさ」の2つの点数で診断するので、うまく遊んでも、わざと偏らせても楽しめる

## ルール

1. 12日間、毎日「今日のメニュー」を組む。1日に選べるのは3種目まで。同じ種目を何回選んでもよい
2. 「トレーニング開始」で、選んだ種目が鍛える部位の筋肉が育つ
3. 同じ部位を続けて鍛えると筋肉痛（赤く表示）になり、伸びが落ちる
4. 「休養日にする」を選ぶと筋肉痛が消え、次の日は超回復で伸びが1.3倍になる
5. 「🍙 食事管理」で、食べる量（減量・維持・増量・爆食い）とタンパク質（少なめ・ふつう・多め）を決められる。決めなくても遊べる（おまかせ＝維持・ふつう）。決めた内容は変えるまで毎日続く
6. 12日目が終わると、体型の診断と「美しさ」「おもしろさ」の点数が出る

### 種目（18種目）と主に鍛える部位

| グループ | 種目 |
|---|---|
| 押す筋肉（胸・肩・二の腕） | ベンチプレス、腕立て伏せ、ダンベルフライ、ショルダープレス、サイドレイズ、ディップス |
| 引く筋肉（背中・力こぶ・前腕・首まわり） | 懸垂、ラットプルダウン、ダンベルカール、シュラッグ、リストカール |
| 体幹（腹筋） | クランチ、プランク |
| 脚（お尻・もも・ふくらはぎ） | スクワット、デッドリフト、レッグカール、ヒップスラスト、カーフレイズ |

各種目は複数の部位に重み（例：ベンチプレス＝胸1.0・二の腕0.5・肩0.35）を持つ。部位は12か所（首まわり、肩、胸、力こぶ、二の腕、前腕、背中、腹筋、お尻、もも前、もも裏、ふくらはぎ）。

## 得点と称号

### 点数（0〜100）

12部位の筋肉量の平均を `mean`、ばらつき（標準偏差÷平均）を `cv` とする。

- 美しさ ＝ 100 × (1 − max(0, cv − 0.18) / 0.8) × √(mean / 0.6) × 体脂肪ペナルティ（各項は0〜1に収める）
  - 体脂肪ペナルティ ＝ max(0.2, 1 − max(0, fat − 0.9) × 0.45)
- おもしろさ ＝ 100 × ((cv − 0.35) / 1.4) × √(mean / 0.25) ＋ 18 × max(0, fat − 1.2)（上限100）

### 体型の診断（上から順に判定）

| 条件 | 称号 |
|---|---|
| 平均がほぼ0（mean < 0.12） | ひょろひょろ（体脂肪が多ければ、ぽっちゃり系） |
| 1部位だけが突出（最大部位 ≥ 1.2、かつ他の平均の3倍＋0.3以上） | 部位ごとの称号（首が消えた人、肩にジープ、大胸筋が歩いてる人、力こぶ一点豪華主義、二の腕番長、前腕だけ職人、背中に羽、腹筋だけ板チョコ、お尻が主役、太もも競輪選手、もも裏番長、ふくらはぎダイヤモンド） |
| 腕（力こぶ・二の腕・前腕）だけが発達 | 腕だけゴリラ |
| 上半身が下半身の2.2倍以上 | チキンレッグ |
| 下半身が上半身の2.2倍以上 | 下半身だけアスリート |
| 体脂肪が多い（fat ≥ 1.7） | ぽっちゃりパワー系（mean ≥ 1）／ぽっちゃりさん |
| 体脂肪が少なく（fat ≤ 0.12）、mean ≥ 0.8、cv ≤ 0.5 | キレッキレの仕上がり |
| cv ≤ 0.4、mean ≥ 0.4 | ナイスバルク！モンスター級（mean ≥ 1.6）／黄金比ボディ（mean ≥ 0.7）／バランス良しの細マッチョ |
| 肩と背中が平均の1.5倍以上で、脚もそれなり | 逆三角形ボディ |
| どれにも当たらない | 個性派ボディ |

プレイ中も、画面上部に「いまの体型」として同じ診断が表示される。

## 画面構成

| 画面 | 内容 |
|---|---|
| タイトル | ロゴ、説明文、ルールの要点5つ、「ジムに入る」ボタン |
| プレイ中 | 上部：DAY表示（例：DAY 3/12）、いまの体型、体脂肪％、「🍙 食事管理」ボタン、効果音ボタン。中央：キャラクター（SVG）とかけ声の吹き出し、伸びた部位の表示。下部：グループ別の種目一覧。固定バー：今日のメニュー（3枠、タップで外せる）、「休養日にする」「トレーニング開始」 |
| 食事管理（シート） | いまの体脂肪とバー、食べる量・タンパク質の選択、効果の説明、「おまかせに戻す」「決定」 |
| 結果 | 完成した体、称号と説明、体脂肪と食事内容、美しさ・おもしろさのメーター、部位ごとの筋肉量（多い順）、「もう一度」「結果をシェア」 |

シェア文：`12日間の筋トレで「称号」が完成！ 美しさ○・おもしろさ○（体脂肪○%） #ムキムキ育成ジム` ＋ページのURL

## 主要パラメータ

| 名前 | 値 | 意味 |
|---|---|---|
| `DAYS` | 12 | 日数 |
| `SLOTS` | 3 | 1日に選べる種目数 |
| `VMAX` | 8 | 部位ごとの筋肉量の上限 |
| `GROW` | 0.24 | 1種目あたりの基本の伸び |
| `FAT0` | 0.35 | 開始時の体脂肪（表示は 6 + fat × 13 ％ ≒ 11%） |
| 休養後の伸び | ×1.3 | 休養日の翌日だけ |
| 筋肉痛 | 疲労 f（0〜1） | 伸び ×(1 − 0.5 × f)。鍛えると f ＋0.45×重み、1日ごとに ×0.3、休養日で0 |

1回の伸び ＝ `GROW` × 種目の重み × (1 − 0.5 × 疲労) × 休養ボーナス × 食事倍率

### 食事倍率と体脂肪

| 食べる量 | 伸び | 体脂肪（1日あたり） |
|---|---|---|
| 減量 | ×0.8 | −0.12 |
| 維持 | ×1.0 | 0 |
| 増量 | ×1.25 | ＋0.08 |
| 爆食い | ×1.5 | ＋0.18 |

| タンパク質 | 伸び |
|---|---|
| 少なめ | ×0.85 |
| ふつう | ×1.0 |
| 多め | ×1.2 |

- トレーニングした日は、体脂肪が「0.005 × 種目数」減る
- 体脂肪は0〜2.6の範囲

## 見た目・演出

- キャラクターは正面向きの全身SVG。部位ごとの筋肉量に応じて輪郭が太くなる。体脂肪が多いとお腹が出て腹筋が埋もれ、少ないと筋肉の溝が見える
- 筋肉痛の部位は赤みがかる。疲労が大きいと表情が「つらそう」になる
- 部位のグループ色：押す＝赤（#D7263D）、引く＝青（#1E5AA8）、体幹＝黄土（#C99A0E）、脚＝緑（#2E9E5B）。ダークモードでは明るめの色に切り替え
- トレーニング時は体がふくらむアニメーション（pump）と、ボディビル大会風のかけ声（例：「肩にちっちゃいジープ乗せてんのかい！」「腹筋6LDK！」）
- 効果音（Web Audio）：種目の追加・削除、枠がいっぱい、トレーニング（低音のドンと上昇音）、吹き出し、休養、結果発表のファンファーレ
- 動きを減らす設定（prefers-reduced-motion）では、アニメーションを止める

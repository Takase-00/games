## コンセプト

- 題材：洗濯物を干して、たたむ
- ひとひねり：洗濯ばさみのずれも、折り目のずれも、全部しあがりに響く。100点は、24回のとめと36回の折りが全部ぴったりのときだけ
- 風の強い日は、とめ方が甘いと洗濯物が飛んでいく。たたんだ服の山が傾くと崩れる。失敗にも称号がある

## ルール

1日は「干す → 乾く → たたむ」の順に進み、これを4日くり返す。1日に干す服は3枚（全12枚）。

### 干す（制限時間16秒）

1. 洗濯かごの服を、竿のところまで引っぱって離すと、竿にかかる
2. 竿のあたりをタップ（または押して位置を合わせてから離す）すると、その位置を洗濯ばさみでとめる。1枚につき2か所（両肩・両はし）
3. 服は風で揺れているので、狙う位置（タオル＝両方の角、Tシャツ＝両肩の縫い目、ズボン＝ウエストの両はし）に合わせてタイミングよくとめる。1か所とめると、その側は揺れなくなる
4. 時間切れで、かごに残った服は「干し忘れ」、とめ終わっていない服は空振り扱いになる

### 乾く

- 少しすると突風が吹く。とめ方が甘い服（2か所の「ささえ」の合計が、その日の基準より小さい）は飛んでいく

### たたむ（制限時間26秒）

1. 乾いた服が1枚ずつ、たたむ台に出る
2. 服の端をつかんで引っぱり、重ねたい位置で離すと折れる。点線どおりに3回折る
3. 逆向きに折ると「逆向き」になる
4. たたみ終わった服は、左下の山に積まれる。ずれた服ほど山が傾き、傾きが大きくなると山が崩れる
5. 時間切れになると、残りはたたみ途中のまま積まれる

### 4日間の天気

| 日 | 干す服 | 風 |
|---|---|---|
| 1日目 | タオル、タオル、Tシャツ | そよ風 |
| 2日目 | タオル、Tシャツ、ズボン | ふつう |
| 3日目 | Tシャツ、ズボン、Tシャツ | つよめ |
| 4日目 | ズボン、Tシャツ、ズボン | 強風 |

## 得点と称号

### 1回ごとの判定

| ずれ | とめ・折りの表示 |
|---|---|
| 1.5px以内 | ◎ ぴったり |
| 4px以内 | ○ おしい |
| 9px以内 | △ ずれ |
| それ以上 | × 大ずれ（とめが大きく外れると「× 空振り」） |

- とめの点 ＝ 1 − (ずれ − 1.5) / 8（0〜1に収める）。空振りは0
- 折りのずれは、点線との位置の差と角度の差から求める。折りの点 ＝ 1 − (ずれ − 1.5) / 10（0〜1に収める）。逆向きは0

### 1枚のしあがり

- しあがり ＝ （2か所のとめの平均）×（3回の折りの平均）²
- 表示：◎（100%）、○（70%以上）、△（35%以上）、×（それ未満）
- 飛んだ服・干し忘れた服は0

### 総合点

- 点数 ＝ 12枚のしあがりの平均 × 100（小数点以下切り捨て）

### 称号（上から順に判定）

| 条件 | 称号 |
|---|---|
| 100点 | たたみの人間国宝 |
| 飛んだ服が4枚以上 | 洗濯物を空へ返す人 |
| おかしな折り方（逆向き・大きく外れた折り）が6回以上 | 前衛たたみアーティスト |
| 95点以上 | ホテルのリネン係 |
| 85点以上 | 角がそろう人 |
| 山が2回以上崩れた | 山くずしの名人 |
| 飛んだ服が2枚以上 | 風に愛された人 |
| 65点以上 | きちんと派 |
| 45点以上 | ふつうにたためる人 |
| 25点以上 | たたみ見習い |
| 10点以上 | とりあえず山積み派 |
| それ未満 | 洗濯物と和解できない人 |

## 主要パラメータ

| 名前 | 値 | 意味 |
|---|---|---|
| `HANG_TIME` / `FOLD_TIME` | 16 / 26 | 干す・たたむの制限時間（秒） |
| `PIN_PERF` / `PIN_TAU` | 1.5 / 8 | とめの「ぴったり」の許容（px）／0点になるまでの幅 |
| `FOLD_PERF` / `FOLD_TAU` | 1.5 / 10 | 折りの「ぴったり」の許容／0点になるまでの幅 |
| `PIN_EXP` / `FOLD_EXP` | 1 / 2 | しあがりの式の指数 |
| `FOLD_ARM` | 35 | 折りの角度のずれを測る範囲（点線の中心から±px） |
| `KH` | 0.5 | 竿に干したときの縮尺 |
| 風の揺れ幅 `A` | 2.5 / 4.5 / 6.5 / 8.5 | 1〜4日目 |
| 突風に耐える基準 `G` | 0.40 / 0.90 / 1.20 / 1.45 | 1〜4日目。2か所の「ささえ」の合計がこれ未満だと飛ぶ |
| 山が崩れる傾き | 34（3枚以上積んだとき） | |
| 空振りの範囲 | タオル：外6・内33、Tシャツ：外は袖の先まで・内29、ズボン：外6・内20 | 狙う位置からのずれ（px） |

## 見た目・演出

- 晴れた空と物干し竿。服の色は、タオル（生成り・サーモンピンク）、Tシャツ（黄・水色・薄いグレー）、ズボン（紺・茶）から選ばれる。濡れているあいだは青みがかった濃い色で、乾くと元の色になる
- 洗濯ばさみは赤・黄・緑・青の4色
- 服は風で左右に揺れる。片側をとめると、反対側だけがはためく。突風で飛んだ服は空へ舞っていく
- 折るときは、ドラッグに合わせて折れた形が予告表示される。ぴったり折ると洗濯ばさみ色の火花が散る
- 判定の文字（◎ ぴったり、○ おしい、△ ずれ、× 大ずれ、飛んだ！、山がくずれた！、しあがり ◎ 100% など）が浮かぶ
- 効果音（Web Audio）：服を持つ・竿にかける、とめる（ぴったり／ふつう）、空振り、突風、飛ぶ、折る（ぴったり／ふつう）、1枚のしあがり、残り時間のカウント、日の終わり、山くずれ、時間切れ、結果発表
- ライト・ダークモード対応。動きを減らす設定では、ロゴの揺れや火花を止める

## コンセプト

- 題材：朝の満員電車
- ひとひねり：毎朝どんどん混んでいく電車に、長押しで「ぐいぐい」乗りこむ。乗客は押されるとつぶれ、「むぎゅ」「すみません…」と声が出る
- 何日連続で出勤できるかを競う。結果は駅名標の形で称号を出す（前後の称号が「← 前の駅」「次の駅 →」として並ぶ）

## ルール

1. 電車がホームに着き、ドアが開く
2. まず降りる人が出てくる。降りる人がいなくなるまで、ドアの横で待つ（降りる人にぶつかりながら押すと「降りる人が先！」と注意される）
3. 画面を長押しすると、自分（赤い▼と白い縁取りの人）が指の方へぐいぐい進む。パソコンでは矢印キーでも動かせる
4. 発車ベルのあと「ドアが閉まります」となり、ドアが閉まる。それまでに車内に入れば乗車成功で、翌朝（次の日）へ進む
5. 車内に入れないと「乗りそびれた」、ドアの位置にいると「ドアに挟まった」でゲーム終了
6. 日を追うごとに乗客が増え、乗車時間が短くなり、手ごわい乗客が加わる

### 日ごとに増える要素

| 日 | 内容 |
|---|---|
| 3日目〜 | リュックを背負った人（後ろ向きで大きめ） |
| 4日目〜 | となりの列から一緒に乗りこむライバル |
| 6日目〜 | 大柄な人 |
| 8日目〜 | ドア前から動かない人（スマホを見ている）。14日目からは2人 |
| 12日目〜 | せっかちな人（ライバルの一部がより強く押す） |

日をまたぐときの画面には「○日目（曜日）」と、その日のヒント（例：「ドアが閉まるのが早くなった」）が出る。曜日は月〜金をくり返す。

## 得点と称号

### スコア（1日ごと）

- 乗車成功：100点 ＋ 早さボーナス ＋ 奥ボーナス
  - 早さボーナス ＝ 車内に入った時点の残り秒数 × 12（0〜60点）
  - 奥ボーナス ＝ (車内での奥行き − 6) × 2.4（0〜60点）
- 成功時の表示：「ギリギリセーフ！」（残り0.7秒未満）、「奥までスイスイ！」（奥ボーナス45以上）、「スマート乗車！」（早さボーナス40以上）、それ以外は「乗車成功！」

| 10〜 | つり革見習い |

## 画面構成

| 画面 | 内容 |
|---|---|
| タイトル | 駅名標風のロゴ（GY 00、ぎゅうぎゅうつうきん、Gyu-Gyu Tsukin、← おふとん／かいしゃ →）、説明、ルール3つ、「出勤する」ボタン、ベスト記録、版番号。背景ではCPUのお手本デモが動く |
| プレイ中 | 上部：○日目（曜日）・路線名、スコア、効果音ボタン。案内表示（LED風）：「まもなく電車がまいります」「降りる人が先です」「ご乗車ください」「奥へお詰めください」「ドアが閉まります」（点滅）などと残り秒数。中央：真上から見たホームと車内 |
| 日の切り替え | 「○日目（曜日）」とヒントのワイプ |
| 結果 | 「遅刻」のハンコと失敗の理由（例：「8日目（水）の朝、ドアに挟まった。」）、称号の駅名標（番号＝連続日数、前後の称号と次の称号まであと何日）、説明、連続出勤・スコア（ベスト更新の表示）・ベスト、「結果をシェア」「もう一度」 |

シェア文：`ぎゅうぎゅう通勤｜○日連続で出勤して、○日目に（乗りそびれた／ドアに挟まった）。称号「○」スコア○点` ／ `#ぎゅうぎゅう通勤` ／ページのURL

## 主要パラメータ

座標の1単位は約4cm。ドアの幅は30。

| 名前 | 値 | 意味 |
|---|---|---|
| 混雑（乗客数の目安） | 1〜10日目：10 ＋ 2.3 × (日 − 1)、それ以降：30.7 ＋ 1.3 × (日 − 10)。上限70 | 車内の乗客の多さ |
| 乗車時間 `board` | max(2.8, 6 − 0.15 × (日 − 1)) 秒 | ドアが開いてから発車ベルまで |
| 降りる人 | 1日目は2人。以降、5日目まで1〜3人、11日目まで0〜3人、それ以降0〜2人 | |
| ライバル | 3日目まで0人、4日目は1人、7日目まで0〜1人、13日目まで1〜2人、それ以降1〜3人 | |
| リュックの人の割合 | 3日目から 0.08 ＋ 0.015 × (日 − 3)、上限0.3 | |
| 大柄な人の割合 | 6日目から 0.04 ＋ 0.01 × (日 − 6)、上限0.15 | |
| 動かない人 | 8〜13日目は1人、14日目からは2人 | |
| せっかちな人の割合 | 12日目から0.35 | |

## 見た目・演出

- 真上から見た構図：砂利と線路、電車の車体（ラインカラーは緑 #13A07A）、ロングシート、黄色い点字ブロックのホーム
- 乗客は頭と肩を丸で描いた人物。スーツ・ブラウス・学ラン・セーラー服・私服、髪型、メガネ、ヘッドホン、スマホ、本、居眠りなど。押されると楕円につぶれ、苦しい顔と汗が出る
- 自分の頭上には赤い▼。最初は「あなた」の札が出る。力を入れているときは踏んばる顔、乗れたら笑顔、ドアに挟まると横につぶれる
- 押しているときは「ぎゅっ」「むぎゅ」「ぐいっ」「すみません…」などの吹き出し、押された乗客から「うっ」「ぐえ」「せまい…」
- 乗車中は、オリジナルの発車メロディが流れる
- 効果音（Web Audio）：到着、ドアが開く、発車ベル、ドアが閉まる、発車、乗車成功、乗りそびれ、ドアに挟まる（端末が振動に対応していれば振動も）、押す声、降りる人への注意
- ライト・ダークモード対応。動きを減らす設定では、揺れや上下の動きを止める

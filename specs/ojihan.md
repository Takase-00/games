## コンセプト

- 題材：会社の書類の押印
- ひとひねり：「お辞儀ハンコ」（部下のハンコを上司の印へ向けて少し傾けて押す、という俗説のマナー）を本気で採点する。上司の役職によって正しい角度（会釈15°・敬礼30°・最敬礼45°）がある
- 傾けすぎると「土下座ハンコ」、さらに傾けると「逆さハンコ」になる。変な押し方にも称号がある。結果は「辞令」で役職が言い渡される

## ルール

1. 書類が流れてくる。押印欄が3〜4つ並び、「あなた」の欄のとなりに上司の印（役職と名前）がある
2. 上司の印がある側のボタン（「左へお辞儀」「右へお辞儀」）を長押しすると、ハンコがその方向へ傾いていく。傾くスピードはだんだん速くなる
3. 指を離すと押印。上司の役職に合った角度に近いほど高評価
4. 60秒で何枚さばけるかと、礼儀力（お辞儀の正しさ）で評価する
5. 開始20秒で「後輩が配属！」：反対側に後輩の印が置かれることがある（偉い人のほうへお辞儀する）
6. 開始40秒で「定時前ラッシュ！」：ハンコが傾くスピードがさらに上がる
7. パソコンでは ← → キーの長押しでも遊べる

### 役職と正しい角度

| 役職 | 角度 | お辞儀 |
|---|---|---|
| 主任・係長 | 15° | 会釈 |
| 課長・部長 | 30° | 敬礼 |
| 専務・社長 | 45° | 最敬礼 |

## 得点と称号

### 1枚ごとの判定

| 判定 | 条件 | 点 | 礼儀力 |
|---|---|---|---|
| ◎ 完璧なお辞儀 | 正しい角度との差が5°以内 | 100 | 100 |
| ○ 良いお辞儀 | 差が12°以内 | 60 | 80 |
| △ 浅いお辞儀／深すぎるお辞儀 | 差が12°より大きい | 30 | 45 |
| ▽ 土下座ハンコ | 70°以上 | 20 | 20 |
| × 棒立ちハンコ | 5°未満 | 5 | 0 |
| × そっぽ向きハンコ | 上司のいない側（空欄）へ傾けた | 0 | 0 |
| × 後輩にお辞儀 | 後輩の側へ傾けた | 10 | 10 |
| ↻ 逆さハンコ | 135°以上 | 0 | 0 |

- 連続ボーナス：◎か○が続くと、2枚目から ＋10点ずつ増える（上限＋100点）。それ以外の判定で途切れる
- 総合点 ＝ 各判定の点 ＋ 連続ボーナスの合計
- 礼儀力（%）＝ 礼儀力の平均

### 称号（辞令）

上から順に判定する。

| 条件 | 称号 |
|---|---|
| 0枚 | 幽霊社員 |
| 25枚以上で、◎が9割以上 | お辞儀ハンコ道 家元 |
| 4枚以上で、逆さが半分以上 | 反逆の逆さ印鑑 |
| 4枚以上で、土下座が半分以上 | 平身低頭の土下座マイスター |
| 4枚以上で、棒立ちが半分以上 | 直立不動の鉄人 |
| 4枚以上で、そっぽ向き＋後輩が半分以上 | 我が道を行く一匹狼 |
| それ以外 | 「礼儀力の前置き」＋「枚数の役職」 |

- 礼儀力の前置き：90%以上「礼節を極めし」、75%以上「折り目正しい」、55%以上「まあまあ礼儀正しい」、35%以上「ちょっと頭が高い」、それ未満「無礼講な」

## 見た目・演出

- 事務机の上の書類。書類の種類（稟議書、経費精算書、始末書、ハンコ廃止の稟議書 など）と件名（「会議の進め方を決める会議」「ハンコの角度について」など）がランダムに出る
- 上司の印は朱色の丸い印影に役職と名字（田中、鬼塚、金剛 など）。押印のあと、判定に合わせて印がうなずく・すねる・跳ねる・震える
- 傾けている間は分度器が出て、15°ごとに目盛りの音が鳴る。ハンコを持つ人の顔も、直立・お辞儀・土下座・逆さで変わる
- 判定ごとの擬音（ピタッ、ポン、ペコ、ズサーッ、プイッ、グルン など）と、上司のひとこと（「見事な角度だ」「頭が高いな」「顔を上げたまえ！」「反逆か!!」など）
- 効果音（Web Audio）：始業のチャイム、角度の目盛り、判定ごとの押印音、バナー、残り5秒のカウント
- ライト・ダークモード対応。配色は落ち着いた緑がかった事務机と朱色のアクセント（#C2302A）

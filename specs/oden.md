## コンセプト

- 題材：おでん屋台の鍋番
- ひとひねり：具ごとに煮え方がちがう。煮すぎた大根は崩れ、早すぎる卵は白いまま。お客さんの好み（ふつう・くたくた好き・かため好き）に合わせて、食べ頃を見きわめて出す
- 煮すぎて具が溶けたり、まかないで大将が食べすぎたりしても、それに合った称号がもらえる

## ルール

1. 開店時の鍋は空。画面下の「具のバット」をタップすると、その具が鍋（4×3の12マス）の空いているマスに入る
2. 鍋の具は時間とともに「生 → かため → 食べ頃 → 極上 → 煮すぎ」と変わり、煮すぎてから9秒で溶けて消える。溶けた具は食品ロスとして、その具の値段が売上から引かれる
3. 鍋の具をタップすると、その具を注文しているお客さんのうち、いちばん喜ぶ人に出す。注文している人がいなければ「まかない」（自分で食べる）になり、その具の値段が売上から引かれる
4. お客さんは最大5人。吹き出しに注文（1〜3品）と、待てる時間のバーが出る。時間切れになると怒って帰る
5. 注文をすべて出し終えると帰る。全部「食べ頃」以上なら心付け（チップ）がもらえる
6. 60秒で閉店。残り5秒になると新しいお客さんは来ない

- 具のバットには、具の名前と食べ頃までの秒数が出る。どの具が注文に足りないかは表示しない（v1.1で削除）。お客さんの吹き出しを見て判断する
- 鍋の各マスには、煮え具合のラベル（生／△かため／◎食べ頃／★極上／×煮すぎ）と、煮え具合のゲージが出る
- 出すとちょうどよい具（評価が0.9以上になる具）は、点線の枠が光る

## 得点と称号

### 売上

- 1品の売上 ＝ 具の値段 × 評価の倍率（10円単位で四捨五入）
- 心付け ＝ 全品が食べ頃（倍率0.9以上）なら 50円 × 品数
- 食品ロス：まかない（注文のない具を出した）と、煮すぎて溶けた具は、その具の値段 × `LOSS_RATE`（10円単位で四捨五入）を売上から引く。売上は¥0より下がらない

| お客さんの好み | 生 | かため | 食べ頃 | 極上 | 煮すぎ |
|---|---|---|---|---|---|
| ふつう（ご注文） | 0 | 0.4 | 1.0 | 1.5 | 0.3 |
| くたくた好き（おじいさん） | 0 | 0.2 | 0.9 | 1.0 | 1.5 |
| かため好き（子ども） | 0.3 | 1.5 | 0.9 | 0.9 | 0.2 |

- 3人目以降のお客さんは、15%でくたくた好き、15%でかため好き

#### 条件に使う数の数え方

| 項目 | 数えるタイミング |
|---|---|
| 売上 | 閉店時の売上（食品ロスで引かれた後） |
| 出した数 | 注文しているお客さんに具を出した回数（評価が低くても数える） |
| まかない | 注文している人がいない具をタップした回数 |
| 崩した大根 | 大根が溶けて消えたとき、または煮すぎの大根を鍋から出したとき（お客さんに出しても、まかないでも） |
| 溶けた具 | 煮すぎになってから9秒たって鍋から消えた具の数 |
| 白い卵 | 生かかための卵を、かため好き以外のお客さんに出した回数（まかないは数えない） |
| おじいさんの大喜び | くたくた好きに煮すぎの具を出した回数（評価1.5倍になるのはこのときだけ） |
| 子どもの大喜び | かため好きにかための具を出した回数（評価1.5倍になるのはこのときだけ） |
| 怒って帰った客 | 待てる時間がなくなって帰ったお客さんの数 |

## 主要パラメータ

| 名前 | 値 | 意味 |
|---|---|---|
| `DURATION` | 60 | 1回のプレイ時間（秒） |
| `MELT` | 9 | 煮すぎになってから溶けて消えるまでの秒数 |
| `NAMA_RATIO` | 0.55 | 食べ頃になる時刻のこの割合までは「生」 |
| `GOKU_BAND` | 0.2 | 食べ頃の窓の中央 ±20% が「極上」 |
| `SEATS` / `COLS`×`ROWS` | 5 / 4×3 | 席の数 / 鍋のマス |
| `GOOD` / `BEST` | 0.9 / 1.5 | 「満足」「大喜び」とみなす評価の倍率 |
| `LOSS_RATE` | 1.0 | 食品ロス（まかない・溶けた具）で、具の値段のうち売上から引く割合 |
| 称号の売上の基準 `RANK_S` / `RANK_A` / `RANK_B` / `RANK_C` | 13000 / 9500 / 6500 / 4000 | 神様 / 大将 / 一人前 / 見習い |

### お客さん

- 注文の品数：最初の1人は1品（卵かこんにゃく）。開始10秒までは1〜2品、30秒までは1〜3品、それ以降は2〜3品
- 待てる時間 ＝ (9 ＋ 品数×3.5 ＋ いちばん時間のかかる具の秒数×0.6) × (1 − 0.15 × 経過の割合)。くたくた好きは×1.15、かため好きは×0.95
- 席が空いてから次のお客さんが来るまで：0.6〜1.8秒
- 開店時の仕込みはなし（v2.0から。それまでは大根・卵・こんにゃく・ちくわ・はんぺんが少し煮えた状態で入っていた）

### 調整の目安（v3.0、CPUで各1,000回の自動プレイ。神様の確率は5,000回）

CPUは注文と煮え具合を一瞬で読み取るので、人が遊ぶときは「0.5〜1秒に1回操作」の行が近いと考える。

| 遊び方 | 平均売上 | 称号の出方 |
|---|---|---|
| お手本CPU・1.5秒に1回操作 | ¥3,577 | 見張り番 72%、見習い 13%、閑古鳥の番人 10% |
| お手本CPU・1秒に1回操作 | ¥5,503 | 見習い 91% |
| お手本CPU・0.7秒に1回操作 | ¥7,938 | 一人前 69%、ちびっこの味方 25% |
| お手本CPU・0.5秒に1回操作 | ¥10,216 | 大将 86%（神様 0%） |
| お手本CPU・0.35秒に1回操作（人の限界に近い） | ¥11,787 | 大将 91%、神様 約9%（5,000回で9.14%。上位0.1%は ¥14,590） |
| お手本CPU・毎フレーム判断 | ¥13,244 | 神様 58% |
| 検証用の改良CPU・毎フレーム判断、先に6個仕込む | ¥13,633 | 神様 68% |

- 席が4人だったv2.2との比較（同じ腕前の平均）：0.35秒に1回 ¥9,900 → ¥11,822、0.5秒に1回 ¥9,024 → ¥10,217
- 神様を「人の限界に近い速さで0.1%」にするなら、基準は約 ¥14,600

- 理論上の上限は約 ¥26,000（鍋12マスの回転から、60秒で最大約107品 × 1品最大約241円）。来る注文をすべて先読みできる前提なので、実際には届かない

## 見た目・演出

- 屋台の夜：紺ののれん（「お・で・ん・番」）、赤い提灯、木のカウンター、銅色の四角いおでん鍋に仕切り
- 具の絵はCanvasで数値から描く。煮えるほど色が濃くなり、煮すぎると大根は割れて崩れ、卵は割れて黄身が出て、ちくわはふやけ、はんぺんはしぼみ、こんにゃくは縮み、餅巾着は餅がはみ出す
- お客さんは5種類（会社員、OL、学生、おばちゃん、作業員）＋くたくた好きのおじいさん、かため好きの子ども。待ちくたびれると汗、怒ると怒りマーク
- 出すときは具が吹き出しへ飛んでいき、反応（「極上！」「真っ白！」など）と売上が浮かぶ。まかないのときは「まかない（もぐもぐ）」、溶けたときは「溶けて消えた…」と、引かれた額（例：−¥180）が浮かぶ
- 湯気と煮立つ泡のパーティクル。食べ頃の具ほど湯気が多い
- 効果音（Web Audio）：具を入れる、食べ頃になる、煮すぎ、極上・満足・不満、まかない、心付け（コイン）、怒って帰る、来店、溶ける、鍋がいっぱい、残り5秒のカウント、開店・閉店の拍子木
- ライト・ダークモード対応。動きを減らす設定では、揺れやアニメーションを止める
